# Restricciones

| ID | Restricción | Descripción |
|---|---|---|
| RC01 | Aplicación web | El sistema se desarrolla como aplicación accesible desde un navegador web. |
| RC02 | Control de versiones | El código se gestiona con Git y se mantiene en un repositorio compartido (GitHub). |
| RC03 | API REST | La comunicación entre frontend y backend se realiza mediante una API REST. |
| RC04 | Pasarela de pago | Integración con una pasarela de pago externa. |
| RC05 | Servicio de envío | Integración con un servicio externo de envío. |
| RC06 | Backend Node.js | El backend se desarrolla con Node.js (Express). |
| RC07 | PostgreSQL | La información se almacena en PostgreSQL. |
| RC08 | Integración ERP | El sistema se integra con el ERP existente para productos y stock. |
| RC09 | Frontend Angular | La interfaz web se desarrolla con Angular y TypeScript. |
| RC10 | Alcance académico | No se desarrollan nuevas funcionalidades: el trabajo es de análisis, decisión y justificación arquitectónica. |
