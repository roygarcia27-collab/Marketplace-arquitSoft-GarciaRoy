# Actores

| Actor | Tipo | ¿Qué necesita realizar? |
|---|---|---|
| Cliente | Humano | Buscar productos, consultar información, agregar al carrito, realizar pedidos, pagar y consultar sus pedidos. |
| Seller | Humano | Ofrecer, registrar, actualizar y consultar sus productos; gestionar la información de sus ventas. |
| Administrador | Humano | Administrar la plataforma y gestionar sellers. |
| Pasarela de pago | Sistema externo | Procesar pagos. |
| Servicio de envío | Sistema externo | Gestionar información de entrega. |
| Servicio de facturación | Sistema externo | Generar comprobantes de pago. |
| ERP | Sistema externo | Proporcionar información de productos y stock. |
